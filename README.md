# DeepDarkWorld

A custom Minecraft world generator for Paper/Spigot-based servers using Multiverse Core.

This plugin injects a heavy Deep Dark aesthetic into generated worlds by layering sculk-driven terrain, underground sculk patches, and ominous biome behavior while still behaving like a normal custom world generator.

## Why this is OP

- Deep Dark flavor on every generated chunk
- Sculk veins, sculk, and shrieker-style decoration injected into terrain
- Works as a custom generator option for Multiverse
- Built for 1.21.11 Paper API

## Features

- Custom `ChunkGenerator` implementation
- Noise-driven sculk patches
- Surface and underground sculk vein generation
- Multiverse-compatible world generation
- Minimal setup, max creepy vibes

## Requirements

- Paper (or compatible API build) for Minecraft 1.21.11
- Multiverse-Core
- Java 21

## Installation

1. Build the plugin:

```bash
   mvn clean package
```
